## Reading a row

- **tier 1**: plain HTTP was enough. **tier 2**: only TLS impersonation got real HTML. **tier 3**: both were walled; the note says whether it was a status code or a challenge page.
- A `blocked` note with HTTP 200 usually means a JavaScript shell: the server sent a page, and the list is fetched later by the browser. The fix for those is tier 3 or that site's JSON API, not a better selector.
- Sites that answer only behind a login are not attempted by tiers 1-3 at all. The tool reports `blocked` and stops; it does not have your password.
